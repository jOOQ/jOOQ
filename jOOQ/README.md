The jOOQ module contains the runtime library.

Its main features are:

- [SQL building](https://www.jooq.org/doc/latest/manual/sql-building/)
- [SQL execution](https://www.jooq.org/doc/latest/manual/sql-execution/)
- [SQL parsing](https://www.jooq.org/doc/latest/manual/sql-building/sql-parser/)

And much more. Most systems will only include this library as a dependency.
