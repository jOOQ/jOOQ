The `jOOQ-meta-kotlin2` module implements Kotlin extension functions for code generation configuration elements from [jOOQ-meta](https://www.jooq.org/doc/latest/manual/reference/modules/module-jooq-meta/), in order to better use them from a Kotlin script, e.g. when working with Gradle, but not with the official [Gradle plugin](https://www.jooq.org/doc/latest/manual/reference/modules/module-jooq-codegen-gradle/).
